# Case Study Notes

These are evidence notes, not prompt templates.

## Successful test — late-night laundromat

Observed strengths:
- clear establishing shot
- one small practical problem
- reaction-led progression
- object close-up
- quiet hand-contact beat
- larger final landing panel
- real black/white print structure improved after explicit medium correction

Lesson:
A tiny event can carry a page if the reaction chain and panel hierarchy are clear.

## Failed test — cafeteria page with character reference images

Observed failure:
- paneling became somewhat more coherent
- relationship focus improved
- medium remained sepia / warm gray
- skin retained smooth digital modeling
- hair remained painterly
- result looked like manga-framed illustration rather than true black-and-white print

Lesson:
Reference images can silently override the requested medium unless the skill explicitly treats them as identity-only.

Resulting rule:
Requested manga medium outranks reference rendering style.

## Evidence policy

When future tests reveal a stable rule:
- record what changed
- distinguish observation from interpretation
- update the skill only when the rule is repeatable or clearly tied to a failure mode
