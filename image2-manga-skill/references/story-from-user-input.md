# Story From User Input

## Purpose

Convert simple user input into a page-sized story without forcing the user to provide a complete script.

The assistant should preserve supplied facts and invent only what is necessary to make the page readable.

## Input cases

### A. Character + scene are provided

Derive the page from:

**scene affordances × character behavior × relationship tension**

Ask internally:
- What can naturally happen here?
- What small friction already exists in this setting?
- What object or action can carry the beat?
- How would this specific character react?
- How would the other character respond differently?
- What can change by the last panel?

Do not import unrelated drama.

### B. Character is provided, scene is not

Choose a scene that reveals a supplied trait or relationship pattern.

Good scenes for slice-of-life and shoujo often contain small practical friction:
- vending machine
- convenience store
- library shelf
- laundromat
- train platform
- umbrella
- food tray
- broken strap
- tangled scarf
- wrong drink
- missing small object

The location should create behavior.

### C. Scene is provided, character personality is not

Do not invent a lasting personality profile.

Create only temporary contrast needed for the page:
- one acts / one hesitates
- one notices / one misses it
- one says it / one avoids saying it
- one is practical / one interprets emotionally

These are scene functions, not canon.

### D. Character and scene are both missing

Use the manga mode.

#### Slice-of-life A
small intention → ordinary friction → character-specific reaction → response → tiny payoff

#### Shoujo A
relationship state → opportunity → unspoken feeling → observable cue → perception shift → emotional landing

## Character × Situation → Beat

Use this algorithm:

1. **Immediate intention**  
   What does someone want to do right now?

2. **Natural friction**  
   What small obstacle comes from the environment?

3. **Character-specific reaction**  
   What makes the response belong to this character?

4. **Other-character response**  
   The second character must have their own logic.

5. **Micro-shift**  
   Change at least one variable:
   - distance
   - understanding
   - initiative
   - embarrassment
   - possession of an object
   - emotional certainty
   - awareness

A page without a shift is only a vignette.

## Avoid generic relationship writing

Do not default to:
- one person has a problem
- the other person solves it attractively
- instant romantic payoff

Prefer reciprocal behavior:
- both misread
- both hesitate differently
- one notices something the other hides
- an object passes between them
- a joke changes who has initiative
- a practical action becomes emotionally legible

## Page-scale plotting

A one-page manga usually needs only:

- **Beginning** — establish state
- **Development** — action or interaction
- **Turn** — something changes
- **Landing** — leave a readable after-effect

Do not force a major climax.

The shift can be tiny if it is visible.
