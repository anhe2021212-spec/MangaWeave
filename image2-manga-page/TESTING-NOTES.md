# Testing Notes

## What this version is trying to test

1. Does black-and-white manga still hold when direct colored references are demoted?
2. Does page breathing remain improved?
3. Does panel hierarchy recover from the “even grid” tendency?
4. In Shoujo-A, do we again see:
   - one dominant emotional panel
   - asymmetry
   - micro interruption panels
   - occasional more expressive geometry

## Suggested comparisons

### A. Text-only identity anchor
Use only textual character identity.
Best for testing whether the skill itself can build hierarchy.

### B. Mono-character anchor
First generate black-and-white anchor images.
Then generate the page.
Best for continuity testing.

### C. Direct colored reference
Keep as control group only.

## What to watch for

### Good signs
- one panel clearly carries the page
- one or two small panels act as pause or interruption
- not every panel is equally sparse
- black-and-white feels printed rather than filtered

### Bad signs
- calm evenly sized rectangles
- all panels have the same importance
- every panel feels airbrushed or politely empty
- asymmetry has vanished
